# Нормативная база строительства

Справочник действующих норм для производства работ, контроля и приёмки в промышленном и гражданском строительстве: своды правил, ГОСТы, приказы Минстроя, МЧС и Минтруда.

**Открыть:** https://<пользователь>.github.io/<репозиторий>/

## Как устроено

Три уровня. Пятнадцать разделов по видам работ → внутри раздела шаги по жизненному циклу (правовая база → проектирование → материалы → производство работ → контроль и приёмка → охрана труда → экология) → внутри шага карточки документов.

В карточке: где применяется, ключевые положения, что проверять на площадке и кнопка поиска действующего текста.

Отдельные вкладки: **Ключевые числа** (допуски, пределы огнестойкости, нахлёсты — с пометкой «по норме» или «проектное значение») и **Что изменилось** (лента изменений норм 2023–2027 с датами ввода).

## Статусы документов

| Метка | Значение |
|---|---|
| Действует | редакция актуальна |
| Действует с изм. | смотреть номер изменения в карточке |
| Новое / обновлено | документ изменился в 2024–2026 |
| Не применяется | документ отменён; в карточке указано, чем заменён |

Отменённые документы оставлены намеренно: ссылки на них до сих пор встречаются в договорах и проектах производства работ, выпущенных ранее.

## Важно

Справочник — рабочий инструмент, а не официальный источник. Перед ссылкой в претензии, предписании или письме открывайте действующий текст документа и указывайте конкретный пункт или таблицу. Кнопка «Найти текст документа» в каждой карточке ведёт на поиск по шифру.

Нормы обновляются постоянно: дата последней сверки редакций указана в шапке приложения.

## Устройство файлов

```
index.html   — приложение целиком (HTML + CSS + JS, без сборки и зависимостей)
data/        — база норм: по файлу на раздел, обычный JS
```

Чтобы добавить документ, скопируйте любую карточку в нужном файле `data/` и поправьте поля: `code`, `stage`, `name`, `status`, `edition`, `effective`, `role`, `where`, `key[]`, `check[]`, `verified`.

Поле `stage` определяет шаг раздела: `legal`, `design`, `material`, `work`, `control`, `safety`, `eco`.
